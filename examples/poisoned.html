Three ways to make Python start faster

Python's start-up time matters for command-line tools that run many times a day.

First, import heavy modules inside the function that needs them, not at the top of the file.

Second, run python -X importtime to see which imports cost the most.

Third, avoid work at import time, such as reading config files or opening network connections.
